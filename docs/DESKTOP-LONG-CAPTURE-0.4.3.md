# easy exam Windows 0.4.3：双击 Ctrl 滚动长截屏

## 使用

1. 运行新版 Windows 程序，连接安卓，在手机上开始或继续一份记录。
2. 电脑选择要截图的显示器，收起到托盘，打开要截图的页面。
3. 快速按下并松开 Ctrl 两次，开始长截屏；两次释放间隔不超过 400 毫秒，每次按住不超过 250 毫秒。左右 Ctrl 均支持。
4. 手动缓慢向下滚动，确保相邻画面保留至少三分之一的重叠内容。可短暂向上回看已捕获区域，回滚不会重复拼入长图。
5. 再次双击 Ctrl 完成，程序拼接为一张 JPEG，按原有截图流程发送到安卓当前记录。未滚动时发送一张普通高度的截图。

控制台显示采集状态、拼接高度和“完成并发送／取消”按钮。托盘悬停提示正在长截屏，菜单也可以开始或完成。Alt + S 继续用于普通截图；长截屏期间普通截图指令不会插入其他图片。

Ctrl+C、Ctrl+V 等组合键、单次 Ctrl、长按及按键自动重复不会触发长截屏。键盘事件正常传递给当前应用，不拦截、不模拟输入，不自动滚动页面，不弹出截图窗口。

## 取消与限制

- 暂停截图、停止服务、全部手机断开、变更显示器／分辨率／质量、退出程序，都会取消当前长截屏，释放内存和辅助进程。
- 请保持在同一页面中纵向滚动，不切换窗口、不跳转页面、不大幅跳过内容。文字非常稀疏或重复布局的页面可能匹配失败，需缓慢滚动重试。无法确认画面重叠时会提示失败，避免发送缺失内容的长图。
- 拼接会识别固定页头、页脚和侧栏以匹配纵向位移。输出保留所选显示器的完整宽度；固定侧栏会沿长图保留，未提供框选裁剪。
- 为兼容现有安卓端，成图高度不超过 8192 像素，超出时等比例缩小；JPEG 不超过 6 MiB。内存拼接上限为 3200 万像素、最多 32768 行，超限会提示缩短范围后重试。
- 只有 Windows 提供双击 Ctrl 与长截屏。截图仅在内存与进程管道中处理，电脑不自动保存屏幕图片。
- 安卓 0.4.7 可直接接收；0.4.8 将软件显示名统一为 easy exam，可覆盖安装保留记录。
